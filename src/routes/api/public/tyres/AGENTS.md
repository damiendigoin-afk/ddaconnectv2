# Public tyre rules (src/routes/api/public/tyres, src/lib/tire-*)
- CentralePneus: the dataLayer `price` is HT; the source price is the TTC shown in the product card with the same identifier, checked against dataLayer×1.2 (±3 %), otherwise the item is dropped. Why: reading the dataLayer as TTC divided by 1.2 twice and underpriced every tyre.
- Tire quote prices go through priceTireLine in src/lib/tires.ts (base HT + applyMargin, ×quantity, VAT 20 %, + parameterised mount); never recompute tire totals elsewhere. Why: one formula for screen, margin lever, history and PDF.
- Web tire quote = POST /api/public/tyres/quotes (route delegates to src/lib/tire-web-facade.server.ts; contract/whitelist in tire-web-api.ts). Web mode is Top prix only (web_supplier='top_prix', outside QuoteTireSupplierKey) via runTopPrice (tire-top-price-core.ts, shared with the internal Top prix option, sources injected: server-direct reads, no provider-status writes). Order: config (disabled/incomplete => 503) -> origin -> bounded strict body -> persistent atomic quota RPC tire_web_quota_hit (fail closed) -> bounded in-memory cache + in-flight dedupe -> 25 s deadline. Activation guarded by DB trigger: top_prix + explicit site (Districash account is per site, never another site) + Districash credentials + https origin. Why: public exposure only through one audited, whitelisted path.
- Tire « Top prix » is only an extra option of the existing Fournisseur selector (TOP_PRICE_OPTION, outside QuoteTireSupplierKey); quoteTopPriceTires returns the usual buildSevenOffers structure (requested brand + 6 tier×season slots, same slots/titles/pricing) and only replaces each slot's offer with pickTopPriceOffers' cheapest conforming one across all suppliers: CentralePneus all brands per season (fetchPublicTiresAllBrands, rules in tire-top-price-source.ts) + legacy consultation (requested brand, local catalogue) + Districash without indices sent. Tier resolution: see the brand reference rule below; no reliable tier => excluded and listed as unclassified. Why: user's historical quote flow must stay identical.
- Top prix brand rotation reuses the consulted offer pool (result.pool, never sent to the public API) via topPriceBrandAlternatives/nextTopPriceAlternative; brands are compared by normalizeBrandKey. Why: swap one slot without a new search or invented offers.
- Tire brand tiers come from the sourced global reference src/lib/tire-brand-reference.ts (evidence + status per brand; supplier category alone never enters it), applied in every quote mode via tierOfBrand/tierOfOffer/effectiveTier and applyBrandReference (fetchBrandTiers, web facade). Order: garage-disabled => none; reference; tire_brand_tiers tier (provisional, unreferenced only); supplier tier (provisional); unreferenced brands with diverging supplier tiers in one pool are excluded and reported. tire_brand_tiers keeps only activation/preference order for referenced brands. Why: one global tier per brand, never decided per supplier or garage, never by price.
