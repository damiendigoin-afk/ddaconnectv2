# UI rules (src/components, rules owned by src/lib modules)
- Prix saisis (PA HT…) via PriceInput (src/lib/price-input.ts) : frappe libre virgule/point, conversion au blur seulement. Why: champ numérique contrôlé empêchait de taper « , » / « . ».
- Anti-doublon commande = avertissement + confirmation utilisateur ; jamais unicité métier bloquante (ni trigger ni contrainte en base). Similarité pure dans src/lib/order-duplicate.ts (même site + fournisseur + destination + cible OR > dossier > plaque, au moins une ligne même réf normalisée et même PA HT au centime, quantité indifférente, annulées ignorées) ; OrderForm alerte, confirme « Valider quand même » et garde un verrou synchrone anti-double-clic. Why: recommander le même pneu est légitime.
- Supplier product links (productUrl) are internal-only: shown via supplierProductLink in TireQuoteSheet `internal` mode (print:hidden), never in PDFs, client quotes or shared views. Why: supplier name, URL and cost must never reach customers.
- Home unknown-plate Ixellio lookup reuses IxellioVehicleLookup (variant home) + lookupIxellioVehicle; only well-formed plates (wellFormedPlate) absent from local search results are offered, never auto-called; definitive answers cached per tab in ixellio-lookup-cache.ts, vehicle saved only on click. Why: no needless Ixellio calls on the single-seat licence.
- Liste d'approvisionnement (procurement_lists / procurement_list_lines, src/lib/procurement*.ts, UI ProcurementList.tsx) : émetteur du document = information, jamais fournisseur ; source_price_ht = prix source, jamais PA (lignes de commande générées avec expected_unit_cost_ht NULL) ; 1 ligne = 1 fournisseur ; génération uniquement via RPC generate_procurement_orders (verrou liste, OR obligatoire, une commande detailed/destination or par fournisseur, lignes déjà générées figées, part_orders.procurement_list_id sans source_document_id pour ne pas déclencher le garde-doublon). Why: réutilisable par Carrosserie, idempotent, moteur réception existant inchangé.
- Tour 4 pneus : prompt groupé = TIRE_STEP_PROMPT intégral par roue ; parseTourTiresResponse refuse toute roue vide (erreur + Réessayer, jamais synthèse « non déterminée ») ; écran TourTiresAnalysis sans bouton devis. Why: EP-353-YN, réponse IA hors schéma affichée comme vide.
- Tour 4 pneus : la dimension IA complète (ex. 155/65 R14 75T) est séparée en dimension + indices via normalizeTireRequirement (src/lib/tour-tire-analysis.ts) à l'analyse et au chiffrage ; clé d'idempotence FO = tour + destinataire + empreinte du contenu (payloadFingerprint). Why: recherche fournisseur vide et 409 invalid_idempotent_request sur EP-353-YN.
- Districash devis : connecteur lecture seule (districash-quote.functions.ts -> districash-session.server.ts), une connexion par chiffrage, offres J/J+ seulement, PA = data-filtreprixachat (price_kind purchase_ht), saison seulement si lisible dans le libellé. Why: connexion + catalogue validés le 15/10/2026.
- Districash tyre orders from the quote ("Commander chez DC") create an internal part_order with status `to_transmit` + manual portal validation; `ordered` requires a real supplier order number (SQL guard guard_part_order_transmit). No transactional portal call until an API is documented. Why: never claim a supplier order without proof.
- Districash server session (src/lib/districash-session.server.ts): host allowlist districashv2.inoshop.net, paths /, /login, /search only (plus GET /cart, GET /catalog/product/... and POST /cart/store for the cart flow), one login attempt per call, returns statuses only. Test 15/10/2026: login form (Laravel, CSRF, no captcha) opens a session for both accounts, search must be sent as x-www-form-urlencoded (districashSearchBody, protocol confirmed in Chrome); live validation of this form still pending. Not wired into quotes until a live search returns products with EAN + price. Not used by the UI.
